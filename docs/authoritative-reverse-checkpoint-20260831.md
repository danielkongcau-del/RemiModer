# 权威逆向成果检查点（2026-08-31）

本提交声明：在已经冻结的 **Remielle Origin 客户端原生控制器定义边界**内，本仓库代码所生成并由本地证据绑定的结果，是截至 2026-08-31 的权威逆向成果。

“权威”在这里严格表示：结论仅来自游戏本体资产、GameAssembly/UnityPlayer 原生代码、IL2CPP 运行时或完整性合格的本地运行记录，以及对这些来源进行的机械派生；未用社区实现、表现猜测或人为补写的控制器逻辑填充未知项。

## 已达到的终态

- 冻结完成合同包含 14 个核心 Claim，14/14 为 `CLOSED` 或 `CLOSED_OPAQUE`。
- Remielle Origin 的序列化控制器根、Animator 拓扑、Behavior/Task/Ability 所有权、必要运行时实例关系、动态调用端点和输出引用已经进入有限原生证据图。
- 188 个序列化类型和 353 个间接调用点的扩展审计已完成，并转入非阻塞 Engine Audit 附录。
- 14 个先前未观察动态调用端点均由静态 receiver/slot/function-pointer 合同闭合；运行时端点缺口为零。
- v43 的 13 个分支输入探针保留为可选诊断单元，不是当前完成条件，也不需要激活。

最终完成状态、原生图、证据模型和轨迹检查产物只保留在本地 `extracted/analysis/`，由 `.gitignore` 阻止提交。仓库提交的是可复现这些结论的代码、Schema、测试和不含游戏原件的审计说明。

## 结论边界

该检查点证明的是“客户端原生控制器定义取得完成”，不声称：

- 已恢复开发者原始 C++ 源码或全部混淆前名称；
- 已穷举所有队伍、敌人和战斗时序；
- 已编写可脱离游戏运行的替代控制器；
- 已取得只存在于服务端的内部逻辑；
- 已完成模型、渲染、灯光、特效、镜头和音频演出等其他总目标。

未知原始名称和不需要继续展开的引擎实现保留为带精确 RVA/body/ABI 或字段合同的 `CLOSED_OPAQUE`，不会被研究别名冒充为游戏原名。
